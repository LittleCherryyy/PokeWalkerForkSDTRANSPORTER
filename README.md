# PokeWalkerForkSDTRANSPORTER
Pokéwalker Virtual is an open-source project that connects Pokémon HeartGold and SoulSilver on Nintendo DSi to an Android-based Pokéwalker emulator via local Wi-Fi. It aims to enable wireless Pokémon transfers, preserve the original in-game experience, and provide an interactive Android app with customizable Pokéwalker widgets.
